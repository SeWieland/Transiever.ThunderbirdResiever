# Contributing

This beta especially needs redacted real-world Thunderbird reports from Windows and Linux.

Include the Thunderbird version, OS, installation type, `tbrx` diagnostics, and only the smallest fixture needed to reproduce a problem.
Never submit a complete profile, credentials, message content, or private mailbox data.

Pull requests are welcome.
Use Conventional Commits for titles and commits when practical, and keep parser changes backed by synthetic fixtures.
